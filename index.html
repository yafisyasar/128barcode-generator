Barcode API

Generate barcodes programmatically from any app — perfect for printing labels or integrating with other systems.

/api/barcode?value=1234567890

Send a GET /api/barcode?value=1234567890 or POST /api/barcode with JSON body { "value": "1234567890" }. The response is an image/png of the Code 128 barcode. Optional params: scale and height. CORS is enabled, so the API can be called from any domain.

QR API

Generate styled or plain QR codes programmatically — send format=qrcode to the same API.

/api/barcode?value=https://example.com&format=qrcode

GET or POST { "value": "...", "format": "qrcode" }. Optional params: eclevel (L, M, Q, H), scale. The response is an image/png QR code.
